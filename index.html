Questions, answered.

The short version of how Tourmate, Solo2Squad and Group Finder fit together.

01What is Tourmate?

Tourmate is the front door to three connected tools: Tourmate.ai builds an itinerary, Solo2Squad sets up the trip and matches you with a small group, and Group Finder lists open trips you can join. Each one picks up where the last one ends.

02Do I need an account to look around?

No. You can browse the tools and see how they work without signing up. You will need a free Solo2Squad account when you want to create a trip or request to join one.

03Which tool should I start with?

Know where you want to go but not how? Start with Tourmate.ai. Ready to plan a trip or find people? Go to Solo2Squad. Want something that is already coming together? Open Group Finder and join it.

04How does joining a squad work?

You request to join a trip and the host accepts, with group capacity enforced so a trip never overfills. Once you are in, the squad gets a private chat, a shared itinerary and shared expenses.

05What is the difference between Solo2Squad and Group Finder?

Solo2Squad is where you create and run your own trip and build the squad around it. Group Finder is for browsing trips that are already open, filtered by date, budget and interest, so you can join one instead of starting from scratch.

06Is Tourmate only for solo travelers?

No. Solo travelers are the starting point, but friends can use Solo2Squad to plan together, and anyone can join an open trip. A squad is small by design, so the trip stays friendly.

07I found a bug or have an idea. Where do I send it?

Use the feedback form. It takes about 30 seconds and goes straight to the people who build these tools, and you can rate a specific tool from the feedback section or the Feedback button on every page.
